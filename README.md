# Fragments Test

[![Kotlin](https://img.shields.io/badge/Kotlin-1.8+-blue.svg?logo=kotlin)](https://kotlinlang.org)
[![Platform](https://img.shields.io/badge/Platform-Android-green.svg?logo=android)](https://www.android.com/)
[![Architecture](https://img.shields.io/badge/Pattern-MVVM-blueviolet.svg)](https://developer.android.com/topic/architecture)

Тестовое приложение для изучения работы с Fragment и ViewModel в Android. Демонстрирует коммуникацию между фрагментами и активностью через Shared ViewModel.

## Функциональность

- Два фрагмента с взаимной коммуникацией
- Общая ViewModel для обмена данными
- LiveData для наблюдения за изменениями
- Динамическое управление фрагментами (добавление/удаление)

## Технологии

- Kotlin
- Fragments
- ViewModel
- LiveData
- ViewBinding
- activityViewModels
